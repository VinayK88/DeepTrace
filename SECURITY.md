# Security & Research Boundary

DeepTrace is a defensive, synthetic content-integrity research project.

- It does not scrape social networks or private accounts.
- It does not identify, deanonymize, or target real people.
- It does not make factual claims about real political events or campaigns.
- It does not generate deceptive media or automate influence operations.
- Current provenance, media-forensics, account, narrative, and campaign data are synthetic fixtures.
- C2PA-like fields model provenance validation outcomes; this repository does not yet perform cryptographic C2PA manifest validation.

A production implementation should use authorized data sources, real C2PA/Content Credentials validators, audited media-forensics models, calibrated uncertainty, human review, privacy controls, abuse monitoring, and jurisdiction-appropriate governance.
